O CSS permite controlar o espaçamento dos elementos utilizando propriedades como margin, padding e border.

O modelo de caixa

Todo elemento HTML pode ser entendido como uma caixa. Essa caixa possui o conteúdo, o espaçamento interno (padding), a borda (border) e o espaçamento externo (margin).

Com essas propriedades podemos organizar melhor os elementos da página e criar layouts mais agradáveis e fáceis de ler.
